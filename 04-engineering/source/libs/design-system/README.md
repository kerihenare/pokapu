# Design System

`@pokapu/design-system`: shared interface components and design tokens for Pokapu's apps.

This is the code counterpart to the [style guide](../../../../03-design/style-guide/) and [brand guidelines](../../../../03-design/brand-guidelines/). Guidance agreed in design should be implemented here, so apps share one consistent, accessible interface.

## Status

The package is an empty manifest. No framework, components, or tokens exist yet, and how the package is built and consumed hasn't been decided.
