# Source

Pokapu's application source code. Run package commands from this directory, not from the repository root.

## Layout

- `apps/`: deployable applications and their end-to-end tests.
  - [`web`](apps/web/) (`@pokapu/web`): the TanStack Start web app. So far it's a single placeholder page.
  - [`web-e2e`](apps/web-e2e/) (`@pokapu/web-e2e`): Playwright end-to-end and accessibility tests for `@pokapu/web`.
- `libs/`: shared libraries used by apps.
  - [`design-system`](libs/design-system/) (`@pokapu/design-system`): empty so far.

Shared configuration lives at this directory's root and applies to every package: `tsconfig.base.json` (each package's `tsconfig.json` extends it), `.oxlintrc.json`, `.oxfmtrc.json` and `vitest.config.ts`.

## Stack

- **Language and runtime:** TypeScript 7 (strict, ES modules) on Node.js 26 LTS. See [TypeScript on Node.js](../decisions/261109-typescript-on-node-js.md).
- **Web framework:** TanStack Start with React, built with Vite and served as a plain Node.js server through Nitro. See [TanStack Start as the web framework](../decisions/261109-tanstack-start-web-framework.md).
- **Database:** PostgreSQL 17 or later (developed against 18). See [PostgreSQL as the database](../decisions/261109-postgresql-database.md).
- **Data access:** Drizzle ORM over node-postgres, with SQL migrations generated by drizzle-kit, then reviewed and committed. See [Drizzle ORM and SQL migrations](../decisions/261109-drizzle-orm-and-sql-migrations.md).
- **Linting and formatting:** Oxlint (type-aware, with the TypeScript, React, jsx-a11y and import rules) and oxfmt. See [Oxlint and oxfmt](../decisions/261109-oxlint-and-oxfmt.md).
- **Testing:** Vitest (Browser Mode for components) and Playwright with axe-core for end-to-end and accessibility tests. Database tests run against real PostgreSQL through Testcontainers. See [Testing with Vitest and Playwright](../decisions/261109-testing-with-vitest-and-playwright.md).
- **CI:** GitHub Actions on every pull request and push to `main`. See [GitHub Actions for CI](../decisions/261109-github-actions-ci.md).
- **Package manager:** pnpm workspaces covering `apps/*` and `libs/*`. See [pnpm workspaces](../decisions/261109-pnpm-workspaces.md).

## Setup

1. Install Node.js 26. The version is pinned in `.node-version`, which most Node version managers read.
2. Install pnpm at the version pinned in `package.json` (`packageManager`). Node.js 25 and later no longer include Corepack, so either run `npm install --global corepack` and then `corepack enable`, or [install pnpm directly](https://pnpm.io/installation).
3. From this directory, run `pnpm install`.
4. Run `pnpm browsers:install` to download the browsers that Vitest Browser Mode and Playwright use.

Docker (or a compatible runtime) will be needed for database tests once they exist.

## Commands

| Command                 | What it does                                                                  |
| ----------------------- | ----------------------------------------------------------------------------- |
| `pnpm check`            | Runs the format check, lint, type-check and tests. Run it before you push.    |
| `pnpm format`           | Formats every file with oxfmt.                                                |
| `pnpm format:check`     | Checks formatting without changing files.                                     |
| `pnpm lint`             | Lints with Oxlint, including type-aware rules. Warnings fail.                 |
| `pnpm lint:fix`         | Lints and applies safe fixes.                                                 |
| `pnpm typecheck`        | Type-checks every package with TypeScript 7.                                  |
| `pnpm test`             | Runs Vitest: `*.test.ts` in Node and `*.test.tsx` in Chromium (Browser Mode). |
| `pnpm test:watch`       | Runs Vitest in watch mode.                                                    |
| `pnpm build`            | Builds every package that has a `build` script.                               |
| `pnpm test:e2e`         | Builds, then runs Playwright in Chromium, Firefox and WebKit with axe checks. |
| `pnpm browsers:install` | Downloads the Playwright browsers.                                            |
| `pnpm audit`            | Fails on dependencies with high or critical security advisories.              |

To work on the web app, run `pnpm --filter @pokapu/web dev` and open <http://localhost:3000>. To run a production build, run `pnpm build`, then `pnpm --filter @pokapu/web start`.

## Conventions

- Test files sit next to the code they test. Name them `*.test.ts` for logic, which runs in Node, and `*.test.tsx` for components, which run in a real browser.
- Every page covered by an end-to-end test must also call `expectNoAccessibilityViolations` (in `apps/web-e2e/tests/accessibility.ts`), which fails on WCAG 2.2 A or AA violations.
- `apps/web/src/routeTree.gen.ts` is generated by TanStack Router when you run `dev` or `build`. It's committed, so type-checking works on a fresh checkout, and it's excluded from linting and formatting.
- oxfmt and Playwright are pinned to exact versions. Upgrade them in their own commit, and commit any reformatting separately.

## Editor setup

Install the Oxc extension for your editor ([VS Code](https://marketplace.visualstudio.com/items?itemName=oxc.oxc-vscode), or any editor through the Oxc language server). It picks up `.oxlintrc.json` and `.oxfmtrc.json` from this directory.

## Status

Formatting, linting, type-checking, unit and component tests, end-to-end and accessibility tests, and CI are all set up. The web app is a placeholder page.

Database tooling isn't set up yet: Drizzle, Testcontainers, the CI migration check and the PostgreSQL 17 and 18 test matrix. It follows [tenant isolation with a shared schema and row-level security](../decisions/261109-tenant-isolation-with-row-level-security.md), which sets the schema rules, database roles and shared isolation test helpers.

These decisions are still open: how plugins are built, and how releases and deployment work.
