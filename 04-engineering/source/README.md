# Source

Pokapu's application source code. Run package commands from this directory, not from the repository root.

## Layout

- `apps/`: deployable applications. None yet.
- `libs/`: shared libraries used by apps.
  - [`design-system`](libs/design-system/) (`@pokapu/design-system`)

## Status

There are no scripts, dependencies, or build tooling yet. The package manager, runtime version, and how packages are linked together haven't been decided. Once they are, record the decision in [`../decisions/`](../decisions/) and add setup instructions here.
