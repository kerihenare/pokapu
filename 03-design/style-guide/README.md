# Style Guide

Visual and content standards for Pokapu's interface, so it stays consistent as more people contribute.

This section will cover:

- layout, spacing, and grid
- colour and typography in the interface
- components and their states
- accessibility requirements
- writing for the interface (British/NZ English, plain language)

Nothing has been decided yet. Record style decisions in [`../decisions/`](../decisions/) and summarise the outcome here. Where guidance becomes code, it belongs in the [design system](../../04-engineering/source/libs/design-system/).
