# Design

How Pokapu looks, feels, and behaves for the people who use it.

Design work should support our [values](../01-organisation/values.md), particularly Radical Inclusion (accessible to everyone) and Immediacy (tools that remove barriers rather than adding them).

## Contents

- [Brand guidelines](brand-guidelines/): Pokapu's identity, including name, logo, voice, and tone.
- [Style guide](style-guide/): visual and content standards for the interface.
- [Wireframes](wireframes/): layouts and flows for screens and features.
- [Decisions](decisions/): design decision records.

The code counterpart to this guidance is the [design system](../04-engineering/source/libs/design-system/) library.

## Recording a decision

Follow [Recording decisions](../99-system/decisions/261109-recording-decisions.md). Name the file `YYMMDD-slugified-title.md` using the date the decision was made.
